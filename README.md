# Hammad Ahmad: Portfolio

Personal portfolio of Hammad Ahmad, AI engineer and MS researcher at Auburn University.

**Live:** https://hamikha.github.io/HammadAhmad_Portfolio/

## Built with

- HTML, CSS and JavaScript (no frameworks, no build step)
- WebGL2 for the interactive point-cloud hero

## Run locally

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

## Structure

```
index.html          page content
assets/css/         styles
assets/js/          scripts
assets/fonts/       fonts
assets/img/         images
```
